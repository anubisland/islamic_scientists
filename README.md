# islamic_scientists
عمل مشروع لمعرفة لعلماء المسلمين فى مختلف المجالات على مدار الوقت بداية من ظهور الاسلام

## الصوت الطبيعي

يعتمد الموقع على ملفات MP3 مولدة مسبقًا عبر `edge-tts` بدل صوت المتصفح الآلي. عند تعديل أي نص عربي أو إنجليزي في بيانات الموقع، أعد توليد الملفات الصوتية:

```powershell
python scripts\gen_tts.py --force
```

ولإعادة توليد مجال محدد أو صوت محدد فقط:

```powershell
python scripts\gen_tts.py --fields 1 --slots warm --langs ar
```
